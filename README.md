# weather-widget
Weather widget for Rainmeter

This repository contains a simple Windows 11-style Rainmeter weather widget focused on Berlin, Germany by default.

## Files
- `WeatherRadar/WeatherRadar.ini` — main Rainmeter skin
- `WeatherRadar/@Resources/Settings.inc` — user-editable location settings
- `WeatherRadar/README.md` — installation and usage instructions

## Installation
1. Copy the `WeatherRadar` folder into your Rainmeter `Skins` directory.
2. Refresh Rainmeter and load `WeatherRadar.ini`.
3. Click `Edit location` in the skin to update `WeatherRadar/@Resources/Settings.inc`.
4. Save the file and refresh the skin.
